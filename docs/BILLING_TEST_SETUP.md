# Test-only billing setup
The edge function explicitly refuses live Stripe keys and events. Configure STRIPE_TEST_SECRET, STRIPE_TEST_WEBHOOK_SECRET, STRIPE_TEST_HOME_PRICE, STRIPE_TEST_PRO_PRICE and EASY3D_APP_ORIGIN on the dedicated Supabase test project, never in frontend or Git. Deploy the function with JWT gateway verification disabled only for the webhook endpoint; the function verifies Stripe HMAC and authenticates checkout via Auth /user. Add webhook events listed in index.ts. Run a real test Checkout and refund/cancel in Stripe sandbox before acceptance; contract fixtures are not actual Stripe checkout. The public ledger is read-only by RLS; billing writes require service role. Do not enable paid-write enforcement from test entitlements. Production requires separate live-mode ledger, audited webhook setup, consumer terms/refund policy, pricing and authorization. Local MIT editor remains free; hosted services are the commercial boundary.
