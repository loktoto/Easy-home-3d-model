# Easy3DHome — proposed launch brand

Brand name provisional; trademark/domain clearance not performed. Keep MIT editor, current root URL, JSON format and localStorage keys. Marketing pages at /welcome/ (English), /welcome/zh-hant/, /welcome/zh-hans/. Editor remains Traditional Chinese; do not market as fully multilingual yet. No paid billing, analytics or new deployment is enabled by this PR.

## Positioning
Measure first. Make room for life. / 買傢俬前，先睇吓擺唔擺得落。

Audience: apartment renters, home owners, furniture buyers, DIY renovators. Core funnel: search or community post → demo or blank plan → first wall → first furniture → saved/exported design. Prioritize search tutorials, real synthetic demo plans, 20-second screen recordings, relevant Reddit/community posts (obey rules), GitHub and Product Hunt. No unsolicited spam.

## Monetization hypotheses
Keep all current local features free. Test optional one-off export/report packs HK$39–79 and pro hosted sync or commercial project workspace HK$49–79/month only after demand validation. Affiliate links require program acceptance, explicit disclosure, licensed product data and no tracking of floor plans. Existing MIT code can be forked; sell hosted convenience/services, not artificial restrictions. No payments yet.

## Next release gates
External live hosting verified, complete editor translation via structured message catalog (all inspector fields, dialog text, error messages, furniture defaults, units, ARIA, dynamic strings; never translate user names or JSON schema), mobile/desktop full workflow and geometry, storage migration, keyboard and real-device Safari/Chrome. Add privacy-conscious event counts only after updating privacy notice; never send plan coordinates, project names or content. Verify old and new standalone bundles. Actual CI results must be checked before merge; no production deployment from this draft.
