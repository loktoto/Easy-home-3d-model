# Cloud configuration (opt-in)
Use a dedicated Easy3DHome Supabase project; never reuse another product database. Apply backend/001-cloud.sql using a reviewed migration. In deployed cloud-config.js set window.Easy3DHomeCloudConfig={url:"https://PROJECT.supabase.co",key:"PUBLIC_PUBLISHABLE_KEY"}; never expose service_role or secret keys. Enable email confirmation, configure legitimate SMTP and redirects, review Auth rate limits, RLS and security advisors. The app uses managed Auth and explicit upload/download, memory-only session and compare-and-swap revision updates. Cloud is disabled by default in unconfigured builds. The separate CI workflow uses a disposable real local Supabase stack; production credentials are not needed. Account-level deletion and production setup must be validated separately.
