# Release gate

Publish only integrated, reviewed commits. The public artifact is allow-listed and includes version.json. Cloud is disabled until deliberately configured on a dedicated hosted instance; self-hosting is supported without paid feature gates. All features remain MIT and free. Never publish backend source, test data, credentials or a full Git checkout. Verify the deployed commit, browser workflows and privacy. The canonical public host is https://easy3dhome.pages.dev/. Verify its exact revision before publication. Retain the legacy origin for local data migration.
