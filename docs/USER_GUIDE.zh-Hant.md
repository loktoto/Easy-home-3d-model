# Easy3DHome｜繁體中文使用教學

[首頁](../README.md) · [English guide](USER_GUIDE.md)

免費開源 2D／3D 裝修規劃工具，使用編輯器毋須 GitHub 帳戶或識寫程式。

## 開始使用

- **網上版：** [開啟正式網站](https://easy3dhome.pages.dev/)。
- **電腦離線使用：** [下載 ZIP](https://github.com/loktoto/Easy3DHomeModel/releases/latest/download/Easy3DHome-offline.zip) → 解壓縮整個資料夾 → 雙擊 `index.html` 用瀏覽器開啟。請勿只移走 HTML 檔案。
- **手機及平板：** 建議使用可正常載入的網上版。工具列可橫向捲動，雙指縮放，按「設定」開啟屬性面板。

## 由零開始設計

1. 選「畫第一間房」，在畫布點兩個對角；不規則房間可用「逐幅畫牆」。亦可選設計模板或「建屋精靈」輸入總長、總闊、房數及一／兩層。
2. 選牆輸入長度、高度、厚度及坐標；可在「專案」切換米、厘米、毫米或英尺／英寸；內部幾何仍以米儲存。
3. 揀「門」或「窗」，按牆身加入開口，再調整闊度及位置。
4. 加入傢俬，調整闊、深、高、旋轉及位置；可鎖定、解除鎖定、複製及刪除。
5. 用「量度」及「檢查」核對基本圖則問題，切換 3D 查看效果。
6. 定期「匯出 JSON」備份；在「專案」可匯入或切換不同圖則。

樓層按鈕可切換目前 2D 樓層，＋／－ 可新增或刪除頂層，最多五層。3D 會疊起所有樓層。刪除樓層前先備份。語言、主題及尺寸單位可在「專案」內切換。英文、繁體中文及簡體中文之外，西班牙文、日文、德文、法文、韓文及葡萄牙文仍標示 Beta。

## 進階功能

以下功能已存在於主分支，公開示範網站可能仍是較舊版本。

| 想做甚麼？ | 操作方法 |
| --- | --- |
| 匯入現有圖則 | 在專案內選圖片描圖，以已知距離標定比例，再調整透明度。 |
| 計算裝修費 | 打開傢俬購物清單或裝修預算，輸入數量、價格及預備金，可匯出 CSV。 |
| 匯出圖片或圖則 | 選 PNG 或 PDF 工具，設定尺寸／比例、預覽及核對實際列印比例。 |
| 檢查空間 | 使用圖則檢查、碰撞及距離提示；圖則標註包含面積估算、指北針、比例尺及門窗資料。 |
| 管理不同設計版本 | 在版本歷史儲存快照，修改前先備份，可比較及還原。 |
| 管理客戶專案 | 輸入客戶及專案資料，亦可加入公司品牌及 Logo 報告。 |
| 雲端同步與共享 | 須按 [Cloud setup](CLOUD_SETUP.md) 自行配置專用後端；公開版本預設停用。 |

面積、碰撞檢查及 PDF 比例不等於正式測量或施工認證，請現場覆尺。

## 常見問題

- **需要註冊嗎？** 使用本機編輯器毋須帳戶；提交 GitHub 意見才需要登入。
- **網站開唔到？** 電腦可用 ZIP 離線方案。網上部署驗證見 [#30](https://github.com/loktoto/Easy3DHomeModel/issues/30)。
- **下載後空白？** 解壓整個 ZIP，用現代瀏覽器開啟根目錄的 `index.html`，並確認 JavaScript 已啟用。GitHub 程式碼預覽不是編輯器。
- **圖則點解唔見咗？** 資料存在原本瀏覽器的 localStorage；更換裝置、網址、瀏覽器或清除資料都可能令圖則無法取回。請匯出 JSON，勿依賴私人瀏覽或本機檔案儲存的持久性。
- **可唔可以直接施工？** 不可以當成正式施工圖則或結構評估。必須由合資格人士現場覆尺及核對結構、法規與安全要求。

[提交問題或建議](https://github.com/loktoto/Easy3DHomeModel/issues/new/choose)（需登入 GitHub）。請勿公開私人住宅圖則、地址、帳戶資料或金鑰。
