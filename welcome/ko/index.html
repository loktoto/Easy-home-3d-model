무료 · 오픈 소스 · 로컬 우선

먼저 측정하고, 생활에 맞는 공간을 만드세요.

공간을 설계하고 가구 치수를 확인하며 2D와 3D로 배치를 살펴보세요. 무료 오픈 소스이며 계정이 필요하지 않습니다.

무료 플래너 열기

편집기는 9개 언어를 지원합니다. 프로젝트 메뉴에서 언어를 선택하세요.

사용 방법

  1. 실제 치수로 벽 그리기
  2. 문, 창문, 가구 추가하기
  3. 3D로 전환하고 간격 확인 및 JSON 내보내기

나의 공간. 나의 데이터.

평면도는 브라우저에 저장됩니다. 브라우저 데이터를 삭제하기 전에 JSON 백업을 내보내세요. 클라우드 동기화는 설정된 경우에만 선택적으로 사용할 수 있습니다.

계획 보조 도구입니다. 가구 구매 또는 공사 전에 현장에서 치수를 확인하세요.
